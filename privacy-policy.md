# Privacy Policy for YTBookmarks

Last updated: [Current Date]

## Data Collection and Usage

YTBookmarks is designed with user privacy in mind. We collect and store only the minimum data necessary for the extension to function:

### Local Storage Only
- Bookmark timestamps and labels
- User preferences (auto-pause, show labels, show prompt settings)
- All data is stored locally on your device using browser storage
- No data is transmitted to external servers

### User Activity
- We track video timestamps and user interactions solely for bookmark functionality
- We interact with YouTube's video player to display bookmarks and handle navigation

## Data Sharing and Transfer
- We do not collect, sell, or transfer any user data to third parties
- All data remains on your local device
- Import/Export feature only works when manually initiated by you

## Data Security
- All data is stored locally in your browser
- No authentication or personal information is required
- No cloud storage or external servers are used

## Changes to This Policy
We may update this privacy policy from time to time. Any changes will be reflected in the "Last updated" date at the top of this policy.

## Contact
If you have questions about this privacy policy, you can raise an issue on our GitHub repository.

## Your Rights
Since all data is stored locally on your device, you have complete control over your data. You can:
- Clear all bookmarks using the clear all function
- Remove the extension to delete all stored data
- Export your data at any time for backup
